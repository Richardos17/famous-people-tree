# Famous People Tree – Requirements

## 1. Search & Tree Display
- As a user, I want to search for any person by name so that I can see their ancestors and children in a tree visualization up to 3 generations.
- As a user, I want the tree to load quickly so that I don’t experience delays while exploring.
- As a user, I want the tree to be interactive so that I can expand, collapse, and navigate different branches.

## 2. Data Source
- As a user, I want the app to fetch people’s data from Wikidata so that the information is accurate and up-to-date.
- As a user, I want the app to display fallback info or placeholders if some data (photo, birthdate, country) is missing so that the tree remains readable.

## 3. Person Details
- As a user, I want to click on each person in the tree to see detailed information (name, birthdate, country, photo if available, link to Wikipedia) so that I can learn more about them.
- As a user, I want to see a tooltip preview when hovering over a person so that I can quickly get basic info without opening the detailed view.

## 4. Tree Navigation
- As a user, I want to click a button to see a tree for any person in the current tree so that I can explore their family independently.
- As a user, I want to move up or down to a specific branch so that I can explore lineage without losing my place.
- As a user, I want to export the current tree as an image or PDF so that I can save or share it.

## 5. Connection & Relationships
- As a user, I want to search for two people and see if they are connected through ancestors so that I can discover their relationship.
- As a user, I want the app to show the type of relationship and the nearest common ancestor so that I understand how the two people are related.

## 6. Statistics & Analytics
- As a user, I want to see the oldest ancestor and newest child of a person so that I can understand the span of their family tree.
- As a user, I want to see the origin/country ratio of a person’s ancestors so that I can understand their geographical heritage.

## 7. User Engagement & Popularity
- As a user, I want the app to track how many people have visited a person’s profile so that I can see popularity metrics.
- As a user, I want to see the most popular people on the home page so that I can quickly explore well-known figures.

## 8. Visualizations & UI
- As a user, I want the tree visualizations to have smooth animations so that exploring feels intuitive and engaging.
- As a user, I want the web app to work well on mobile devices so that I can explore trees anywhere.

## 9. Extensions
- As a user, I want to get the average height of all ancestors of a certain person.
- As a user, I want to get the most popular universities attended by ancestors and relatives of a certain person.
- As a user, I want to get the most common jobs of ancestors/relatives.
- As a user, I want to get the most common languages spoken by ancestors/relatives.
- As a user, I want to be able to suggest new relationships which are not on wikidata or add new sources of relationships
